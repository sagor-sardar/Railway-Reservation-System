# Railway Reservation System

## Project Description

Railway Reservation System is a Java-based desktop application designed to manage railway reservations efficiently. The system provides a graphical user interface for users to register, log in, view train information, and make railway reservations.

## Features

- User Registration
- User Login
- Train Information Management
- Railway Ticket Reservation
- Ticket Management
- User Data Management
- Reservation Management
- File-based Data Storage
- Graphical User Interface (GUI)

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling
- Git
- GitHub
